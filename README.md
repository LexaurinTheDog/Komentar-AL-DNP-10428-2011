# Komentar i ligjit nr. 10428, datë 2.6.2011, “Për të drejtën ndërkombëtare private”

Komentar i një akti ligjor shqiptar: **ligji nr. 10428, datë 2.6.2011, “Për të drejtën ndërkombëtare private”** (Fletorja Zyrtare nr. 82, datë 17.6.2011). Komentari përfshin **89 njësi** (nenet 1–89) në 4 kapituj komentari; për çdo nen jepet teksti i plotë i dispozitës dhe komentari.

Gjendja ligjore sipas: **teksti zyrtar i Qendrës së Botimeve Zyrtare (QBZ) në versionin bazë (“base”)**, pa ndryshime të shënuara në tekst (ELI: `http://qbz.gov.al/eli/ligj/2011/06/02/10428`), marrë më 2.10.2026.
